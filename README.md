# OI 入门：从 Python 到 CSP-J 的 C++ 语言基础

> 一套学习课件，面向**有一定 Python 基础、零散看过 C++ 书**（简单语句、条件、循环懂一点，但没有系统学过）、想系统打好 C++ 语言基础、为 CSP-J / GESP / NOIP 做准备的小朋友，适合小学高年级到初中。
>
> 本资料**只管“语言基础”**——学完后能用 C++ 把想法准确、规范地写出来。算法（枚举、模拟、贪心、搜索、DP……）是下一阶段的事。

## 一、课程定位：起点与终点

### 1. 起点：有 Python 基础意味着什么

| 已经有的（可以快速带过） | Python 给不了的（必须重点补） |
|---|---|
| 变量、赋值、`if`、`for`/`while` 的**逻辑思维** | **类型**：变量必须先声明类型，`int` 会**溢出** |
| 列表、字符串的基本操作概念 | **整数除法 / 取模**的规则与 Python 不同（负数尤其） |
| 函数的概念、调用、返回值 | **编译**：先编译再运行，编译错误要会读 |
| 简单调试（print 大法） | **数组**：定长、下标从 0、**越界不会自动检查**（最危险） |
| | **输入输出格式**：比赛要求严格的格式、保留小数 |
| | **花括号与分号**：语法细节多，初期错误集中在这里 |
| | **引用 / 指针 / 结构体 / STL** 这些 Python 里“隐形”的东西 |

结论：**不需要从“什么是变量”讲起**，但要在“类型、整数运算、数组、输入输出”上**花比 C++ 新手更多的心思去纠正 Python 习惯**。每一课都安排了“从 Python 说起”的对照小节。

### 2. 终点：CSP-J 要求的语言范围

信奥比赛用的 C++ 其实是一个**很小的子集**，不需要学完 C++ Primer。按 NOI 大纲入门级 + CSP-J 真题实际情况，语言层面需要：

- ✅ 必须熟练：基本类型、运算符、分支、循环、一维/二维数组、`char` 与 `string`、函数（含递归、引用传参）、结构体、`sort`、`freopen` 文件读写、`scanf/printf`
- ✅ 需要会用：STL 的 `vector`、`stack`、`queue`、`pair`、`map`、`set`、`priority_queue`
- 🔸 了解即可：指针（主要为了看懂初赛题和链表）、位运算（初赛常考）
- ❌ 基本不用：类与继承、模板编写、异常、多线程、智能指针、IO 流高级用法

> 也正因为如此，**不建议继续啃 C++ Primer**——那是写给软件工程师的，大量内容比赛用不到，还会拖慢进度。本资料就是按“比赛子集”裁剪的。

### 3. 比赛形式简介

- **CSP-J（入门级）**：每年秋季。分**第一轮**（笔试，选择 + 阅读程序 + 完善程序，考计算机基础知识和读代码能力）和**第二轮**（上机编程，4 道题）。
- **GESP（CCF 编程能力等级认证）**：1~8 级，每年多次，难度梯度平缓，**非常适合作为学习过程中的阶段性检验**。本课程学完大约对应 GESP C++ 3~4 级的语言要求。
- **考试环境不是 VS Code**：GESP 官方建议 **Dev-C++ 5.11**；CSP-J/S 第二轮以 **NOI Linux 2.0** 为准，不少省份同时提供 Windows + Dev-C++ 5.11，但**评测统一在 NOI Linux 2.0（g++ 9.3）上进行**（具体以当年 CCF 及本省通知为准）。所以本课程**平时就用 Dev-C++ 5.11 或小熊猫 Dev-C++ 6.7.5 练习**（两者界面一样，老师指定了哪个就用哪个），本地按 C++14 编译，备赛后期再装 NOI Linux 虚拟机熟悉一下（详见第 0 课）。注意 GESP 官网列出的评测选项是 `-std=c++11`，本课程的代码只用 C++11 就有的写法，两边都能通过；不要使用更新标准的语法（如 C++17 的 `auto [k, v]`）。
- 课程中列出的洛谷题号、题名已于 2026-11 逐题核对过。

## 二、课程总体设计

### 设计原则

1. **每课一个主题，按章节推进**：讲解 → 跟着敲 → 课堂练习 → 洛谷刷题 → 自查。短的章节一周左右，较长的章节（第 6、9、11、12 课等）分几次学完。
2. **先能写，再写好**：前 6 课只用最基础的语法，第 7 课起才引入数组、STL 等。
3. **对照 Python 讲**：把已有的 Python 知识当作起点，讲清同一个想法在 C++ 里怎么写、哪些规则需要切换。
4. **题目全部来自洛谷**（www.luogu.com.cn），与洛谷官方“入门”题单高度重合，方便查题解、看讨论。
5. **从第 1 课就按比赛规范写代码**，避免后期再改习惯。

## 三、时间安排建议

按中小学生的课业量，建议**每周 4~5 小时**：

| 时间 | 内容 | 时长 |
|---|---|---|
| 周中 1 次 | 读本课讲义：每个示例**先预测输出，再运行验证，再改一处看变化**；短的核心示例自己敲，长示例可以复制来改 | 1~1.5 h |
| 周中 1 次 | 做本课“课堂练习”，做完再看答案 | 1 h |
| 周末 | 洛谷刷“课后刷题”（先做 ★核心，再按情况做巩固、选做） | 2 h |
| 周末结束前 | 对照“自查清单”逐条过，不会的回头补 | 15 min |

- **总时长**：各课标注的用时加起来约 14.5~16 周，再加上复习周，**预留 18 周左右**比较稳妥（标注用时已包含讲义、课堂练习和刷题，不含复习周）。Python 基础好的话，第 1~6 课可以压缩到 3~4 周。
- **题目分级**：每课题单分为 **★核心**（检验本课核心知识，要独立完成）、**巩固**（默认要做，老师按孩子掌握情况增减）、**选做**（量力而行）、**挑战**（有余力再做）。
- **进度宁慢勿快**：判断能否进入下一课的标准是“掌握本课核心知识，★核心题能**独立** AC（不看题解），并且能讲清楚自己代码每一部分在做什么”。巩固题是否加练，看孩子的实际表现决定。
- 每 3 课左右安排一次**小复习周**：把前面做过的错题重做一遍。

### 阶段里程碑

| 完成到 | 应该达到的水平 | 检验方式 |
|---|---|---|
| 第 3 课 | 能独立写出读入—计算—输出的完整程序 | 洛谷【入门1】做完 80% |
| 第 6 课 | 能写嵌套循环、打印图形、判断质数 | 语言知识覆盖 GESP C++ 1~2 级的大部分 |
| 第 10 课 | 能用数组、字符串、函数、结构体解决模拟题 | 洛谷【入门4~6】做完大部分；语言知识覆盖 GESP 3 级的大部分 |
| 第 12 课 | 会用 STL、`freopen`，能估算程序是否超时 | 语言知识覆盖 GESP 4 级的大部分；具备尝试 CSP-J 第二轮第 1 题的语言基础 |

> “覆盖”不等于“考试准备好了”。GESP 各级考纲里还有本课程没有系统训练的内容（例如几种基础排序算法的手写与比较），报考前请对照官方考纲查漏补缺，并用官方样题或真题自测。

## 四、学完之后：下一阶段路线（简要）

语言基础过关后，进入“算法 + 刷题”阶段，大致顺序：

1. **基础算法**：枚举 → 模拟 → 排序 → 前缀和/差分 → 二分 → 贪心 → 高精度
2. **搜索**：递归 → DFS → BFS → 回溯剪枝
3. **数据结构**：栈/队列应用 → 链表 → 树与二叉树 → 并查集 → 堆
4. **动态规划**：线性 DP → 背包 → 区间 DP
5. **数学**：质数筛、GCD、快速幂、组合计数
6. **真题**：CSP-J 历年第二轮真题（洛谷有整理好的题单）+ 第一轮初赛真题

推荐资料：洛谷官方题单（“算法1-1”至“算法1-7”等系列）、《深入浅出程序设计竞赛（基础篇）》（洛谷出品，和洛谷题单配套）、OI Wiki（oi-wiki.org，当字典查）。

## 五、给家长和老师的几条建议

1. **核心代码一定要自己写出来**。看懂 ≠ 会写：读示例时先预测、再运行、再改一改，最后要能不看示例独立写出来。
2. **报错是正常的**。前几周大部分时间都在和分号、括号、拼写打交道，鼓励孩子先自己读报错、查附录 B。
3. **卡住时分级求助**：先复述题目的输入输出、手算一遍样例；还没思路再看提示或问一个方向；最后才看题解。一般独立想 20~30 分钟再往下一级走，完全不知道从哪下手就早点求助。看完题解后**关掉页面重写一遍**。
4. **建立错题本**（可以是一个文件夹）：记录“错在哪、为什么错、正确写法”。比赛中丢分的往往是这些小错。
5. **比 AC 数量更重要的是规范**：变量名清楚、缩进整齐、`long long` 该用就用、数组开够——这些习惯决定了以后比赛的稳定性。
