2. 知识点

2.1 char 与 ASCII 码

在计算机里，英文字母、数字和常见符号，每个字符都对应一个整数编号（ASCII 码）。本课只处理这类字符（中文不在 ASCII 里，比赛题一般也不会让你逐个处理中文）。必须记住这三段：

字符ASCII 码
'0' ~ '9'48 ~ 57
'A' ~ 'Z'65 ~ 90
'a' ~ 'z'97 ~ 122

规律：小写字母 = 大写字母 + 32；同类字符连续编号。

char c = 'A';
cout << c << "\n";            // A
cout << (int)c << "\n";       // 65
cout << (char)(c + 1) << "\n";// B
cout << c + 1 << "\n";        // 66  ← char 参与运算时变成 int

字符的常见操作（不用背 ASCII 数字，直接用字符计算）：

// 判断
if (c >= '0' && c <= '9')   // 是数字字符
if (c >= 'a' && c <= 'z')   // 是小写字母
if (c >= 'A' && c <= 'Z')   // 是大写字母

// 转换
int d = c - '0';            // 数字字符 → 数字：'7' - '0' = 7
char e = d + '0';           // 数字 → 数字字符
char up = c - 'a' + 'A';    // 小写 → 大写
char low = c - 'A' + 'a';   // 大写 → 小写
int idx = c - 'a';          // 'a'→0, 'b'→1, ... 'z'→25，常用来做桶的下标

<cctype> 里也有现成函数：isdigit(c)、isalpha(c)、isupper(c)、islower(c)、toupper(c)、tolower(c)。

2.2 string 的基本使用

#include <string>
string s = "hello";
string t;
cin >> t;                     // 读一个“词”，遇到空格/换行就停

cout << s.size() << "\n";     // 5
cout << s[0] << "\n";         // h
s[0] = 'H';                   // 可以修改 → "Hello"
s = s + " world";             // 拼接 → "Hello world"
s += '!';                     // 追加一个字符
if (s == "Hello world!") ...  // 直接用 == 比较
if (s < t) ...                // 按字典序比较

遍历字符串

for (int i = 0; i < (int)s.size(); i++) {   // string 下标从 0 开始
    cout << s[i];
}
for (char c : s) {                          // 范围 for，类似 Python 的 for c in s
    cout << c;
}

为什么写 (int)s.size()？size() 返回的是“无符号整数”，和 int 比较时偶尔出问题（比如 s.size() - 1 在空串时会变成一个巨大的数）。转成 int 更安全。

2.4 读入一整行

string line;
getline(cin, line);           // 读一整行，包括空格

⚠️ 经典坑：先 cin >> n; 再 getline(cin, line);，getline 会读到 n 后面那个残留的换行符，得到空字符串。解决：中间加一句 getline(cin, line);，把 n 所在那一行剩下的内容连同换行一起吃掉。

int n;
cin >> n;
getline(cin, line);           // 先吃掉 n 所在行剩下的内容（包括换行）
getline(cin, line);           // 现在能正确读到下一行了

这个写法的前提是：要读的文字在下一行。如果题目把文字和 n 放在同一行，第一句 getline 会把它们一起丢掉，那时就要换别的读法。

你可能在题解里见到 cin.ignore();：它只丢掉 1 个字符。如果 n 后面还跟着空格，它只丢掉一个空格，下一个 getline 读到的是剩下的空格，仍然读不到目标的下一行。要用 ignore 就写完整版 cin.ignore(numeric_limits<streamsize>::max(), '\n');（需要 <limits>），意思是“一直丢到换行为止”。

2.5 C 风格字符串：char 数组（了解，能看懂）

#include <cstring>
char s[110];
scanf("%s", s);               // 读一个词（注意不加 &）
int len = strlen(s);          // 长度
for (int i = 0; i < len; i++) ...
  • 末尾有一个隐藏的 '\0' 表示结束，所以要多开一个位置。
  • strlen 每次调用都要数一遍，不要写在循环条件里（for (i = 0; i < strlen(s); i++) 会很慢）。
  • 有时为了下标从 1 开始，写 scanf("%s", s + 1); int len = strlen(s + 1);

建议：日常用 string，看到别人代码里的 char s[] 能读懂即可。

2.6 综合例子：统计单词中每个字母出现次数

#include <iostream>
#include <string>
using namespace std;

int cnt[26];

int main() {
    string s;
    cin >> s;
    for (char c : s) {
        if (c >= 'a' && c <= 'z') cnt[c - 'a']++;
    }
    for (int i = 0; i < 26; i++) {
        if (cnt[i] > 0) cout << (char)('a' + i) << ":" << cnt[i] << "\n";
    }
    return 0;
}

3. ⚠️ 易错点

  1. 'a' 和 "a" 混用：单引号是一个字符（char），双引号是字符串；string s = "a"; 才得到一个 string。
  2. cin >> s 读不到空格后面的内容 → 需要整行用 getline。
  3. cin 后接 getline 读到空行。
  4. 用 int 存 s.size() - 1 之前没转型，空串时出错。
  5. cout << c + 1 输出的是数字而不是字符 → 要 (char)(c + 1)。

// 8-3
#include <iostream>
#include <string>
using namespace std;
int main() {
    string s;
    int k;
    cin >> s >> k;
    k %= 26;                         // 移 26 位等于没移
    // 拓展：如果 k 可以是负数，改成 k = (k % 26 + 26) % 26;
    for (int i = 0; i < (int)s.size(); i++) {
        s[i] = (s[i] - 'a' + k) % 26 + 'a';
    }
    cout << s << "\n";
    return 0;
}
