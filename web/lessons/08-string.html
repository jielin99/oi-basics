1. char 和 ASCII 码

每个字符在计算机里都对应一个整数。必须记住三段：'0'~'9' 是 48~57，'A'~'Z' 是 65~90，'a'~'z' 是 97~122；同类字符连续编号，小写 = 大写 + 32。
