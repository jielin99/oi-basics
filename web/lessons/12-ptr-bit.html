第 12 课 指针、位运算与比赛规范

预计用时：1.5 周 本课目标：理解指针和地址的基本概念（能看懂初赛题）；掌握位运算的基本操作；会用 freopen；会根据数据范围估算时间复杂度；完成一次模拟考试。

这一课的内容分两部分：初赛（笔试）必考的知识和复赛（上机）必备的规范。

分次学习：第一部分（指针）、第二部分（位运算）、第三部分（规范与复杂度）可以分三次学。指针目前要求能看懂初赛题里的短代码；如果目标是 GESP 4 级，指针和参数传递需要另外加练到会写。第 5 节结业的 3.5 小时考场模拟可以等接近备赛时再安排。

第一部分：指针初识

1. 从 Python 说起

Python 里没有指针，但你其实一直在用类似的东西：

a = [1, 2, 3]
b = a          # b 和 a 指向同一个列表
b[0] = 100
print(a)       # [100, 2, 3]

C++ 的指针就是把这件事明着写出来：一个变量里存的是另一个变量的地址。

2. 地址与指针

内存就像一排编了号的格子，每个变量占一些格子，格子的编号就是地址。

int a = 5;
int *p = &a;       // & 取地址：p 存的是 a 的地址；int* 表示“指向 int 的指针”
cout << p << "\n";     // 输出一个地址，如 0x61fe14
cout << *p << "\n";    // * 解引用：p 指向的那个变量的值 → 5
*p = 10;               // 通过指针修改 a
cout << a << "\n";     // 10
符号写在哪含义
int *p声明时p 是一个指向 int 的指针
&a表达式中取 a 的地址
*p表达式中取 p 所指向的值
int &r = a声明时r 是 a 的引用（第 9 课）

💡 现在可以解释第 3 课的 scanf("%d", &n) 了：scanf 需要知道把读到的数存到哪里，所以要传 n 的地址。

3. 指针与数组

在多数表达式中，数组名会转换成指向首元素的指针，所以可以写 int *p = a;。但数组本身不是指针（比如 int a[5] 的 sizeof(a) 是 20，而指针 p 的 sizeof(p) 在 64 位环境下是 8）：

int a[5] = {10, 20, 30, 40, 50};
int *p = a;            // 等价于 p = &a[0]
cout << *p << "\n";        // 10
cout << *(p + 2) << "\n";  // 30，p+2 指向 a[2]
cout << p[3] << "\n";      // 40，p[3] 就是 *(p+3)

这也解释了：

  • sort(a + 1, a + n + 1) 里 a + 1 就是 a[1] 的地址。
  • 数组传进函数时传的是地址，所以函数里能改外面的数组。
  • lower_bound(...) - a 是两个地址相减，得到下标。

🎯 要求：能读懂含有 *、&、指针加减的初赛阅读程序题即可。比赛写代码时几乎不需要自己用指针（链表等结构也常用数组模拟）。

第二部分：位运算

1. 二进制回顾

计算机内部用二进制存数。例如 13 = 8 + 4 + 1 = 1101₂。

十进制转二进制：不断除以 2 取余数，倒着读。

void toBinary(int n) {
    if (n >= 2) toBinary(n / 2);
    cout << n % 2;
}

2. 六种位运算

对两个数的每一个二进制位分别运算：

运算符号规则例子：12 = 1100，10 = 1010
与&都是 1 才是 112 & 10 = 1000 = 8
或|有一个 1 就是 112 | 10 = 1110 = 14
异或^不同为 1，相同为 012 ^ 10 = 0110 = 6
取反~0 变 1，1 变 0~0 = -1
左移<<所有位左移，右边补 03 << 2 = 1100 = 12（相当于 ×4）
右移>>所有位右移12 >> 2 = 11 = 3（相当于 ÷4）

3. 常用技巧

x << k              // x × 2^k
x >> k              // x ÷ 2^k（向下取整，对正数）
1 << k              // 2^k（要得到正数，k 只能是 0~30）
1LL << k            // 2^k（long long 版，k 只能是 0~62）
x & 1               // 判断奇偶：1 是奇数，0 是偶数
(x >> k) & 1        // 取 x 二进制的第 k 位（从 0 开始，从右往左数）
x ^ x               // 0
a ^ b ^ b           // a（异或两次相同的数等于没异或）

⚠️ 位运算优先级很低，一定要加括号：if (x & 1 == 0) 实际是 x & (1 == 0)，要写 if ((x & 1) == 0)。 ⚠️ 1 << 31 得不到正数 2³¹（int 最大只到 2³¹−1），要写 1LL << 31。 ⚠️ 移位的位数必须在 0 ~ 类型位数−1 之间：int 最多移 31 位，long long 最多移 63 位。1LL 只是把左边变成 64 位，1LL << 70 照样不行。入门阶段只对非负数做移位。位数合法、左边非负还不够，x << k 的结果也必须装得下（比如 int 里 1 << 31 位数合法，但结果超出了正数范围）。

4. 初赛常考的相关知识

  • 原码、反码、补码：负数在计算机中用补码表示（-1 的补码是全 1）。
  • 进制转换：二进制、八进制、十进制、十六进制互转。
  • int 是 32 位，范围 −2³¹ ~ 2³¹−1。
  • 1 Byte = 8 bit，1 KB = 1024 Byte，1 MB = 1024 KB。

第三部分：比赛规范与复杂度

1. 文件读写 freopen

CSP 复赛等比赛常要求“从 xxx.in 读入，输出到 xxx.out”：

#include <cstdio>
#include <iostream>
using namespace std;

int main() {
    freopen("sum.in", "r", stdin);
    freopen("sum.out", "w", stdout);

    int a, b;
    cin >> a >> b;
    cout << a + b << "\n";
    return 0;
}

练习方法：在代码所在文件夹新建 sum.in，写入 3 5，运行程序后打开 sum.out 应该看到 8。

🎯 从现在开始，所有在本地做的题，都尝试加上 freopen 来测试。 让它成为肌肉记忆。考场上最惨的事就是“题做对了，文件名写错了，0 分”。

2. 时间复杂度：程序会不会超时

粗略估计：评测机 1 秒大约执行 10⁸ 次简单运算。 这只是数量级估算，不是“算出来不到 10⁸ 就一定能过”：还要看时限、每次操作有多重、有多少组数据，接近上限时要留余量。

数一数程序“最多执行多少次基本操作”：

for (int i = 1; i <= n; i++) ...                        // n 次 → O(n)
for (int i = 1; i <= n; i++) for (int j = 1; j <= n; j++) ...  // n² 次 → O(n²)
for (int i = 1; i <= n / i; i++) ...                    // √n 次 → O(√n)（即 i*i <= n，见第 6 课）
while (n > 0) n /= 2;                                   // log₂n 次 → O(log n)
sort(a + 1, a + n + 1);                                 // O(n log n)

拿到题目先看 n 的范围，倒推需要什么复杂度：

n 的最大值可以接受估算
20O(2ⁿ)2²⁰ ≈ 10⁶ ✅
500O(n³)1.25×10⁸ 勉强
5000O(n²)2.5×10⁷ ✅
10⁵O(n log n)≈ 1.7×10⁶ ✅；O(n²) = 10¹⁰ ❌
10⁶O(n) 或 O(n log n)
10⁹ 以上O(√n)、O(log n)、O(1)

🎯 例：题目 n ≤ 10⁵，你想到的是双重循环 O(n²) → 10¹⁰，肯定超时。要么换更好的算法，要么至少能拿部分分（比赛按测试点给分，小数据能过也有分！）。

4. 课堂练习

练习 12-1：预测输出

int a[4] = {1, 2, 3, 4};
int *p = a + 1;
*p += 10;
p++;
cout << *p << " " << a[1] << "\n";

练习 12-2：输入一个正整数，输出它的二进制表示中有多少个 1。（用 & 1 和 >> 1）

练习 12-3：给你一段代码，估算当 n = 10⁵ 时是否会超时：

for (int i = 1; i <= n; i++)
    for (int j = i; j <= n; j += i)
        cnt++;

（提示：内层循环次数是 n/1 + n/2 + n/3 + ... + n/n，大约是 n × ln n）

练习 12-4：用 freopen 改写第 10 课的成绩排序程序，从 score.in 读、写到 score.out。

点击查看参考答案

12-1：3 12。p 先指向 a[1]，a[1] 变成 12；p++ 后指向 a[2]，值为 3。

12-2：

int n, cnt = 0;
cin >> n;
while (n > 0) {
    cnt += n & 1;
    n >>= 1;
}
cout << cnt << "\n";

12-3：约 10⁵ × 12 ≈ 1.2×10⁶，不会超时。这叫“调和级数”，复杂度 O(n log n)。

B. 新题迁移测评（60~90 分钟，由老师/家长另选没做过的题）。下面只是示例：它印在讲义里，又和练习 7-2 很像，孩子读过或做过就不算新题，正式测评请换题：
