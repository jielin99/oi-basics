环境搭建：让第一个程序跑起来

预计用时：1 小时 本课目标：装好编辑器和编译器；能新建、编译、运行一个 .cpp 文件；注册洛谷并提交第一道题。

1. Python 和 C++ 运行方式的根本区别
PythonC++
运行方式解释执行：python a.py，由解释器直接拿源代码去执行编译执行：先把 a.cpp 编译成 a.exe，再运行 a.exe
错误什么时候出现语法错误在开始执行前就会报出来；其他错误（除以 0、下标越界、名字写错……）运行到那一行才报大部分语法错误在编译时就报出来，一个错都不能有，否则根本生成不了程序
速度慢快（通常快几十倍）——这是信奥用 C++ 的主要原因
  a.cpp  ──(编译器 g++)──►  a.exe  ──(运行)──►  结果
 源代码       编译                 可执行文件

记住：改了代码，一定要重新编译，否则运行的还是旧程序。这是新手最常见的“我明明改了怎么没变”。

2. 考场用什么环境？平时就用什么

信奥考试不是用 VS Code 这类通用编辑器，而是用指定的环境。平时练习最好和考场保持一致，免得考试时手忙脚乱。

考试考场环境评测环境
GESP 等级考试官方建议 Dev-C++ 5.11官方系统（官网“考试环境说明”列出的评测选项是 -std=c++11）
CSP-J/S 第二轮、NOIP以 NOI Linux 2.0 为准；不少省份另外提供 Windows（常见 Dev-C++ 5.11、Code::Blocks），Linux 用虚拟机统一用 NOI Linux 2.0（Ubuntu 20.04，g++ 9.3）

要点：无论考场里用哪个编辑器写代码，最后都放到 Linux 上用 g++ 评测。 所以代码要按标准 C++ 写，不能用 Windows 专有的东西（见附录 C）。每年具体环境以 CCF 和本省的考试通知为准。

主力环境：Dev-C++ 5.11（和考场一致，推荐）

  • 一个安装包里同时带了编辑器和编译器，装完就能用，F11 一键编译运行。
  • 下载：GESP 官网“考试环境说明”页面提供下载；也可以去 SourceForge 搜 “Orwell Dev-C++ 5.11”。
  • 安装后必须做的设置（很重要）：
    1. 工具 → 编译选项，在“编译器”页勾选 “编译时加入以下命令”，填入：-std=c++14 -Wall
      • 原因：5.11 自带的编译器比较老，默认不是 C++14。不加这一条，课程里的 for (char c : s)、auto、to_string 等写法会编译失败。
      • -Wall 会打开更多警告，帮你发现隐藏的 bug。
    2. 工具 → 编辑器选项 → 显示：字体选等宽字体（如 Consolas），字号调大一点。
    3. 编译器下拉框选 TDM-GCC 4.9.2 64-bit Release。
  • 装好后用下面第 3 节的程序检查一下，再编译一段含 for (char c : s) 的代码，确认新标准已经生效（能编译通过只说明至少是 C++11，具体是哪个标准以编译选项为准）。

也可以用 小熊猫 Dev-C++（Dev-C++ 的国产升级版，界面一样，编译器更新，报错提示更友好），刚入门时用着更顺手。但考试前至少 2~3 周要换回 Dev-C++ 5.11 练习，熟悉考场环境。

进阶：NOI Linux 2.0 虚拟机（学完第 12 课后再装）

  • 准备 CSP 第二轮时，在 noi.cn 下载 NOI Linux 2.0 镜像，装进虚拟机（VirtualBox 或 VMware），熟悉 Linux 下的文件管理、编辑器和终端。
  • 会用终端手动编译、运行，考场上最可靠：
g++ a.cpp -o a -std=c++14 -O2 -Wall
./a

在 Windows 上调试通过后，最好再放到 NOI Linux 里编译运行一次，这是各省考试通知里反复提醒的。

VS Code 不用专门学。以后想用可以用，但信奥阶段没有必要。

3. 验证环境：Hello, OI

新建文件 hello.cpp，一个字一个字敲进去：

#include <iostream>
using namespace std;

int main() {
    cout << "Hello, OI!" << endl;
    return 0;
}

编译运行，看到 Hello, OI! 就说明环境 OK。

如果报错，最常见的原因：

  • 中文输入法打出了中文标点（； （ “）→ 切回英文输入法重打。
  • 文件扩展名是 .txt 或 .c 而不是 .cpp。
  • 路径里有中文或空格导致老版编译器异常 → 换个纯英文路径，如 D:\oi\。
4. 注册洛谷并提交第一题
  1. 打开 www.luogu.com.cn 注册账号（请家长协助）。
  2. 打开题目 P1001 A+B Problem，读题：输入两个整数，输出它们的和。
  3. 先在本地写好、测试通过：
#include <iostream>
using namespace std;

int main() {
    int a, b;
    cin >> a >> b;
    cout << a + b << endl;
    return 0;
}
  1. 复制到洛谷提交框，语言选 C++14，提交。
  2. 看到绿色的 AC（Accepted） 就成功了！

评测结果是什么意思

结果含义常见原因
AC通过🎉
WA答案错误逻辑错、输出格式不对、溢出
TLE超时算法太慢、死循环、输入太多却用了慢速读入
MLE超内存数组开得太大
RE运行时错误数组越界、除以 0、递归太深
CE编译错误语法错，或者语言选错了
5. 建议的文件夹组织
D:\oi\
├── lesson01\          每课一个文件夹，课堂示例和练习放这里
├── lesson02\
├── luogu\             洛谷题，文件名就用题号，如 P1001.cpp
└── 错题本\            做错/不会的题，附上一段文字说明错因

用题号命名非常重要：以后复习、找回旧代码会方便很多。
