第 5 课 分支结构

预计用时：1 周 本课目标：熟练写 if / else if / else；会用 switch；会用三目运算符；能处理多条件的分类讨论题。

1. 从 Python 说起

# Python
if score >= 90:
    print("A")
elif score >= 60:
    print("B")
else:
    print("C")
// C++
if (score >= 90) {
    cout << "A\n";
} else if (score >= 60) {     // elif → else if
    cout << "B\n";
} else {
    cout << "C\n";
}

三个变化：

  1. 条件必须用圆括号括起来。
  2. 冒号 + 缩进 → 花括号。
  3. elif → else if（中间有空格）。
🎮 动手看看

2. 知识点

2.1 花括号可以省略吗？

只有一条语句时可以省略花括号：

if (x > 0) cout << "positive\n";

但是这非常容易出错：

if (x > 0)
    cout << "positive\n";
    cnt++;               // ⚠️ 这一行不属于 if！不管 x 是多少都会执行

Python 程序员特别容易掉进这个坑，因为“看起来”缩进对齐了。初学阶段一律写花括号。

🎮 动手看看

2.2 嵌套 if 与“悬空 else”

if (a > 0)
    if (b > 0)
        cout << "both\n";
else                         // 这个 else 属于哪个 if？
    cout << "?\n";

规则：else 总是和离它最近的、还没配对的 if 配对——所以上面的 else 属于 if (b > 0)，缩进是骗人的。这是初赛阅读题的常见陷阱。写花括号就不会有这个问题。

🎮 动手看看

2.3 switch：多路分支

当要判断一个整数（或字符）等于哪几个值之一时，switch 比一长串 if 清晰：

int month;
cin >> month;
switch (month) {
    case 1: case 3: case 5: case 7: case 8: case 10: case 12:
        cout << 31 << "\n";
        break;
    case 4: case 6: case 9: case 11:
        cout << 30 << "\n";
        break;
    case 2:
        cout << 28 << "\n";   // 暂不考虑闰年
        break;
    default:
        cout << "error\n";
}

⚠️ 每个 case 末尾要写 break;，否则会“穿透”继续执行下一个 case 的代码。上面 case 1: case 3: ... 连写就是故意利用穿透，让多个值执行同一段代码。 ⚠️ switch 只能判断整数/字符，不能判断小数、字符串，也不能写范围（case > 90 是错的）。

🎮 动手看看

2.4 三目运算符 ? :

int mx = (a > b) ? a : b;          // 如果 a>b，mx=a，否则 mx=b
cout << (x % 2 == 0 ? "even" : "odd") << "\n";

等价于 Python 的 mx = a if a > b else b。适合简单的二选一，复杂逻辑还是用 if。

2.5 分类讨论的思路：三个数排序

输入三个整数，从小到大输出。（不用数组和 sort）

#include <iostream>
using namespace std;

int main() {
    int a, b, c;
    cin >> a >> b >> c;
    int t;
    if (a > b) { t = a; a = b; b = t; }   // 保证 a <= b
    if (a > c) { t = a; a = c; c = t; }   // 保证 a 是最小的
    if (b > c) { t = b; b = c; c = t; }   // 保证 b <= c
    cout << a << " " << b << " " << c << "\n";
    return 0;
}

交换两个变量要借助中间变量 t（Python 的 a, b = b, a 在 C++ 里不能用）。也可以直接用 swap(a, b);。

2.6 布尔变量做“标记”

bool ok = true;
if (a <= 0) ok = false;
if (b <= 0) ok = false;
if (a + b > 100) ok = false;
if (ok) cout << "Yes\n";
else cout << "No\n";

3. ⚠️ 易错点

  1. if (x > 0); 后面多了分号 → if 管的是一个空语句，后面的 { } 总会执行。
  2. if (x = 0) → 赋值，不是判断。
  3. 省略花括号后又补了第二条语句。
  4. switch 漏写 break。
  5. 输出 Yes/YES/yes 大小写不看题目 → WA。复制题目里的原文。

4. 课堂练习

练习 5-1：输入一个整数，正数输出 positive，负数输出 negative，0 输出 zero。

练习 5-2：输入三条边长（整数），判断能否组成三角形；如果能，再判断是直角、锐角还是钝角三角形。（提示：先排序，设最长边为 c，比较 a²+b² 与 c²。）

练习 5-3：输入年份和月份，输出这个月有多少天（考虑闰年）。

练习 5-4：快递收费：重量 ≤ 1kg 收 8 元；超过 1kg 的部分每 0.5kg 加 2 元，不足 0.5kg 按 0.5kg 算。输入重量（小数），输出费用（整数）。

点击查看参考答案
// 5-4
#include <iostream>
#include <cmath>
using namespace std;
int main() {
    double w;
    cin >> w;
    int cost = 8;
    if (w > 1) {
        int extra = (int)ceil((w - 1) / 0.5);  // 超出部分有几个 0.5kg
        cost += extra * 2;
    }
    cout << cost << "\n";
    return 0;
}
