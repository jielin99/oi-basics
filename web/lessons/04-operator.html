2. 知识点

2.1 赋值与复合赋值

int x = 10;
x += 3;    // x = x + 3   → 13
x -= 2;    // x = x - 2   → 11
x *= 2;    // x = x * 2   → 22
x /= 5;    // x = x / 5   → 4（整除）
x %= 3;    // x = x % 3   → 1

2.2 自增 ++ 与自减 --

int i = 5;
i++;       // i 变成 6
i--;       // i 变成 5
++i;       // i 变成 6

单独成一句时，i++ 和 ++i 完全一样。 区别只在它们被“用在表达式里”时：

int a = 5;
int b = a++;   // 先把 a 的旧值 5 给 b，再把 a 加 1 → b=5, a=6
int c = 5;
int d = ++c;   // 先把 c 加 1，再把新值 6 给 d → d=6, c=6

🎯 写代码时：不要把 ++ 混在复杂表达式里（比如 a[i++] = i++），这种写法甚至是“未定义行为”。 🎯 考初赛时：a++ 和 ++a 的区别是阅读程序题的常客，一定要会。

2.3 关系运算与逻辑运算

// 关系运算：结果是 bool（true=1, false=0）
5 > 3     // true
5 == 3    // false     ← 判断相等是两个等号！
5 != 3    // true

// 逻辑运算
(a > 0) && (b > 0)    // 两个都正
(a > 0) || (b > 0)    // 至少一个正
!(a > 0)              // a 不是正数

短路求值（和 Python 一样）：

  • A && B：A 为假时，B 根本不会计算。
  • A || B：A 为真时，B 不会计算。
if (b != 0 && a / b > 2) { ... }   // 安全：b 为 0 时不会去算 a/b

闰年判断——逻辑运算的经典例子（四年一闰，百年不闰，四百年再闰）：

bool leap = (y % 4 == 0 && y % 100 != 0) || (y % 400 == 0);

2.5 常用数学函数（<cmath>）

#include <cmath>
abs(-5)          // 5       绝对值（整数）
fabs(-2.5)       // 2.5     绝对值（小数）
sqrt(16)         // 4       平方根，返回 double
pow(2, 10)       // 1024    乘方，返回 double！大数会有精度问题
ceil(2.1)        // 3       向上取整，返回 double
floor(2.9)       // 2       向下取整，返回 double
round(2.5)       // 3       四舍五入，返回 double
max(3, 7)        // 7       需要 <algorithm>，两个参数类型必须相同
min(3, 7)        // 3

⚠️ pow 返回 double，用来算整数的乘方可能有误差（如 pow(10, 2) 偶尔得到 99.9999…，转 int 变 99）。整数乘方请用循环自己乘。 ⚠️ max(a, b) 要求两个参数类型完全相同，max(x, 0)（x 是 long long）会编译错误，要写 max(x, 0LL)。

3. ⚠️ 易错点

  1. if (x = 5) 写成了赋值 → 永远为真。判断相等用 ==。
  2. 1 < x < 10 连续比较 → 必须拆成 &&。
  3. 用 pow 算整数乘方再转 int → 可能少 1。
  4. && 写成 &、|| 写成 | → 有时结果碰巧对，有时错，且优先级不同。
  5. 小数比较相等 if (a == 0.3) → 浮点数有误差，应写 if (fabs(a - 0.3) < 1e-9)。
🎮 动手看看
