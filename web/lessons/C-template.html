附录 C：考场代码模板与比赛规范

这些规范从第 1 课起就要遵守。比赛中因为不规范丢分，是最冤的。

1. 起手模板

见 code/模板.cpp。逐行解释：

#include <bits/stdc++.h>   // “万能头文件”，包含所有常用标准库。GCC 支持，比赛可用
using namespace std;       // 省得每次写 std::cout

typedef long long ll;      // 类型别名，少打字
const int N = 100000 + 10; // 数组大小用常量，“+10”是防止边界越界的保险

int a[N];                  // 大数组放全局：①自动初始化为 0 ②不会爆栈

int main() {
    ios::sync_with_stdio(false);  // 让 cin/cout 和 scanf/printf 一样快
    cin.tie(nullptr);
    ...
    return 0;              // 正常结束返回 0（main 不写也默认是 0，本课程约定写上）；返回非 0 可能被判 RE
}

关于万能头：初学时建议先手写具体头文件（<iostream>、<cstdio>、<cstring>、<algorithm>……）一段时间，知道每个函数来自哪里；熟练后再换成万能头。

2. 比赛规范（不注意可能直接丢分）
规范说明
main 函数必须是 int main()不能写 void main()，g++ 直接编译失败。末尾写 return 0; 是本课程约定
严格按题目要求的格式输出不要输出“请输入：”之类的提示语，多输出的内容会被判错。（行末多一个空格、末尾多一个换行，多数评测会忽略，但不要依赖）
文件读写（若题目要求）文件名必须与题目一致，全小写，不要写路径。考前最后检查 freopen 没被注释掉
不能使用 conio.h、windows.h；不要写 system("pause")前两个在 Linux 下没有，直接编译失败；system("pause") 能编译，但 Linux 没有 pause 命令，只会多出报错信息、白白耗时
源文件放在规定的文件夹里CSP 要求每题一个以题目英文名命名的子文件夹，具体看考场说明
不要用 Windows 专有的 %I64d输出 long long 用 %lld，或者直接用 cout

freopen 用法

int main() {
    freopen("apple.in", "r", stdin);    // 从 apple.in 读入
    freopen("apple.out", "w", stdout);  // 输出写到 apple.out
    // 之后 cin/scanf 就从文件读，cout/printf 就写入文件，其他代码完全不用改
    ...
}

考场检查口诀：文件名对不对？注释删没删？return 0 有没有？

3. 数据范围 → 类型与数组大小

读题第一件事：看数据范围。

题目说应该用
数值 ≤ 10⁹int 够用（int 最大约 2.1×10⁹）
数值 ≤ 10¹⁸，或两个 10⁹ 级别的数相乘/累加long long
有小数double（不要用 float，精度太差）
n ≤ 10⁵数组 const int N = 1e5 + 10;

口诀：“十年 OI 一场空，不开 long long 见祖宗。” 拿不准就开 long long。

4. 复杂度估算：程序会不会超时？

粗略估计：评测机 1 秒大约能执行 10⁸（一亿）次简单运算。这只是数量级估算，接近上限时要留余量。根据 n 的大小判断能用多慢的算法：

n 的范围能接受的复杂度典型写法
n ≤ 10O(n!)、O(2ⁿ)全排列、暴力搜索
n ≤ 500O(n³)三重循环
n ≤ 5000O(n²)双重循环
n ≤ 10⁶O(n log n)排序、二分
n ≤ 10⁸O(n)一重循环
n 更大O(log n) 或 O(1)数学公式、二分

第 12 课会详细讲。

5. 代码风格规范
  1. 缩进：每层 4 个空格（或 1 个 Tab），花括号对齐。编辑器一般有“格式化代码”功能（小熊猫 Dev-C++：Ctrl+Shift+A）。
  2. 变量名有含义：sum、cnt、maxScore 好过 a1、b2、xx。循环变量用 i, j, k 没问题。
  3. 一行只写一条语句。
  4. 每道题顶部写两行注释：题号 + 思路，方便日后复习。
  5. 数组下标习惯从 1 开始（for (int i = 1; i <= n; i++)）——信奥题目数据大多从第 1 个开始编号，这样不容易错位；数组记得多开几个（多开只是保险，下标仍然要自己算对）。
