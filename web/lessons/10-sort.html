第 10 课 结构体与排序

预计用时：1 周 本课目标：会定义结构体、结构体数组；会用 sort 排序普通数组和结构体数组；会写自定义比较函数实现多关键字排序。

1. 从 Python 说起

# Python：用元组/字典/类来存一个学生的多项信息，用 sorted 排序
students = [("Tom", 90, 85), ("Amy", 95, 80)]
students.sort(key=lambda s: (-(s[1] + s[2]), s[0]))   # 总分降序，同分按名字升序
// C++：用 struct 打包，用 sort + 比较函数排序
struct Student {
    string name;
    int chinese, math;
};

bool cmp(Student a, Student b) {
    int sa = a.chinese + a.math, sb = b.chinese + b.math;
    if (sa != sb) return sa > sb;   // 总分高的在前
    return a.name < b.name;          // 同分时名字字典序小的在前
}

sort(stu + 1, stu + n + 1, cmp);

2. 知识点

2.1 结构体：自定义一种“打包”类型

struct Student {        // 定义一个新类型 Student
    string name;
    int score;
    int id;
};                      // ⚠️ 末尾的分号不能少！

Student s;              // 定义一个 Student 类型的变量
s.name = "Tom";         // 用 . 访问成员
s.score = 95;

Student stu[1010];      // 结构体数组，存 1000 个学生
stu[1].name = "Amy";

读入 n 个学生：

for (int i = 1; i <= n; i++) {
    cin >> stu[i].name >> stu[i].score;
    stu[i].id = i;      // 记录原始编号，排序后常常需要
}

🎯 为什么要用结构体？如果用三个独立数组 name[]、score[]、id[]，排序时要同步交换三个数组，很麻烦也容易错。结构体把一个人的信息“捆”在一起，排序时整体移动。

2.2 sort：排序神器（<algorithm>）

int a[100010];
// 数组下标 1~n
sort(a + 1, a + n + 1);              // 从小到大
sort(a + 1, a + n + 1, greater<int>()); // 从大到小

// 数组下标 0~n-1
sort(a, a + n);

区间是左闭右开：sort(a + 1, a + n + 1) 排的是 a[1] ~ a[n]，不包含 a[n+1]。和 Python 的 range 一样“不包含右端”。

sort 的时间复杂度是 O(n log n)，10⁶ 个数也能很快排完。比赛中几乎不需要自己手写排序，但冒泡排序、选择排序的原理初赛会考，要能看懂。

2.3 自定义比较函数

比较函数 cmp(a, b) 的含义：返回 true 表示 a 应该排在 b 前面。

bool cmp1(int a, int b) {
    return a > b;              // 大的在前 → 降序
}

bool cmp2(int a, int b) {      // 按个位数从小到大，个位相同按数值从小到大
    if (a % 10 != b % 10) return a % 10 < b % 10;
    return a < b;
}

sort(a + 1, a + n + 1, cmp1);

⚠️ 比较函数里不能写 >= 或 <=，只能用严格的 > 或 <。检验方法：拿一个元素 x 问 cmp(x, x)——“x 应该排在 x 自己前面吗？”答案必须是 false。写了等号，cmp(x, x) 就成了 true，sort 可能排错甚至崩溃。多关键字比较时，所有关键字都相同的两条记录，cmp 也必须返回 false。

2.4 多关键字排序（考试最常见）

按总分从高到低；总分相同按语文从高到低；再相同按学号从小到大。

struct Student {
    int id, chinese, math, english, total;
};
Student stu[310];

bool cmp(Student a, Student b) {
    if (a.total != b.total) return a.total > b.total;        // 第一关键字
    if (a.chinese != b.chinese) return a.chinese > b.chinese; // 第二关键字
    return a.id < b.id;                                       // 第三关键字
}

套路：一层一层比，前面的关键字不相等就直接决定结果，相等才看下一个。

2.5 完整例子

输入 n 个学生的名字和成绩，按成绩从高到低输出，成绩相同的按输入顺序输出。

#include <iostream>
#include <string>
#include <algorithm>
using namespace std;

struct Student {
    string name;
    int score, id;
};
Student stu[1010];

bool cmp(Student a, Student b) {
    if (a.score != b.score) return a.score > b.score;
    return a.id < b.id;
}

int main() {
    int n;
    cin >> n;
    for (int i = 1; i <= n; i++) {
        cin >> stu[i].name >> stu[i].score;
        stu[i].id = i;
    }
    sort(stu + 1, stu + n + 1, cmp);
    for (int i = 1; i <= n; i++) {
        cout << stu[i].name << " " << stu[i].score << "\n";
    }
    return 0;
}

💡 为什么要记 id？因为 sort 不保证相等元素保持原来的顺序（叫“不稳定排序”）。需要保持原顺序时，要么加 id 作为最后关键字，要么用 stable_sort。

2.6 了解：冒泡排序（初赛常考）

for (int i = 1; i < n; i++)              // 进行 n-1 轮
    for (int j = 1; j <= n - i; j++)     // 每轮把最大的“冒”到最后
        if (a[j] > a[j + 1]) swap(a[j], a[j + 1]);

时间复杂度 O(n²)，n 超过几千就会很慢。只需要会读、会分析，比赛写代码用 sort。

3. ⚠️ 易错点

  1. 结构体定义末尾漏了分号。
  2. sort 范围写错：下标从 1 开始却写了 sort(a, a + n)。
  3. 比较函数里用了 >=。
  4. 比较函数里把“前面的关键字”和“后面的关键字”顺序弄反。
  5. 题目要求“相同时按输入顺序”却没有处理。
