第 6 课 循环结构

预计用时：1.5~2 周（题目最多的一课） 本课目标：熟练写 for、while、do-while；会用 break/continue；会写嵌套循环；掌握累加、计数、求最值、判断质数、拆数位等基本套路。

1. 从 Python 说起

# Python
for i in range(1, 11):       # 1 到 10
    print(i)

for i in range(10, 0, -2):   # 10 8 6 4 2
    print(i)

while n > 0:
    n //= 10
// C++
for (int i = 1; i <= 10; i++) {     // 1 到 10
    cout << i << "\n";
}

for (int i = 10; i > 0; i -= 2) {   // 10 8 6 4 2
    cout << i << "\n";
}

while (n > 0) {
    n /= 10;
}

C++ 的 for 括号里三部分，用分号隔开：

for ( 初始化 ; 继续条件 ; 每轮结束后做什么 ) { 循环体 }
      int i=1   i<=10      i++

执行顺序：初始化 → 判断条件 → 循环体 → 更新 → 判断条件 → 循环体 → 更新 → …… → 条件为假时退出。

range(a, b) 对应 for (int i = a; i < b; i++)——注意 Python 的 range 不包含 b。

2. 知识点

2.1 三种循环

// for：知道循环次数时用
for (int i = 1; i <= n; i++) { ... }

// while：不知道次数，只知道什么时候停
while (n > 0) { ... }

// do-while：先执行一次，再判断（至少执行一次），用得少
do {
    cin >> x;
} while (x < 0);    // 注意末尾有分号

2.2 break 和 continue（和 Python 一样）

for (int i = 1; i <= 100; i++) {
    if (i % 3 == 0) continue;   // 跳过 3 的倍数，直接进入下一轮
    if (i > 20) break;          // 超过 20 就结束整个循环
    cout << i << " ";
}

⚠️ break 只跳出最内层的那一个循环。

2.3 五个必会套路

① 累加

long long sum = 0;              // 一定要初始化为 0
for (int i = 1; i <= n; i++) sum += i;

② 计数

int cnt = 0;
for (int i = 1; i <= n; i++) {
    int x; cin >> x;
    if (x % 2 == 0) cnt++;
}

③ 求最大值/最小值

int mx = INT_MIN, mn = INT_MAX;   // 需要 #include <climits>；或者用第一个数做初值
for (int i = 1; i <= n; i++) {
    int x; cin >> x;
    mx = max(mx, x);
    mn = min(mn, x);
}

初值要选得“足够极端”，或者直接用第一个读入的数当初值。INT_MAX / INT_MIN 是 int 的最大/最小值；也可以用 1e9 之类足够大的数。

④ 拆数位（while + % 10 + / 10）

int n = 12345, digitSum = 0, rev = 0;
while (n > 0) {
    int d = n % 10;        // 取出个位
    digitSum += d;
    rev = rev * 10 + d;    // 反转数字
    n /= 10;               // 去掉个位
}
// digitSum = 15, rev = 54321

⑤ 判断质数

bool isPrime = true;
if (n < 2) isPrime = false;
for (int i = 2; i <= n / i; i++) {   // 只要试到 √n。写成 i <= n / i 而不是 i * i <= n：n 接近 int 上限时 i*i 会溢出
    if (n % i == 0) {
        isPrime = false;
        break;
    }
}

为什么只试到 √n？如果 n = a × b 且 a ≤ b，那么 a ≤ √n。所以 √n 以内没有因数，后面也不会有。代码里写成 i <= n / i，意思就是“i × i 不超过 n”：既不用 sqrt 带来的浮点误差，也避免 i * i 在 n 接近 int 上限时溢出。

2.4 嵌套循环：打印图形

外层循环管“第几行”，内层循环管“这一行打印什么”。

// 打印 n 行的直角三角形
// *
// **
// ***
for (int i = 1; i <= n; i++) {
    for (int j = 1; j <= i; j++) {    // 第 i 行打印 i 个星
        cout << "*";
    }
    cout << "\n";
}
// 打印 n 行的等腰三角形（n=3）
//   *
//  ***
// *****
for (int i = 1; i <= n; i++) {
    for (int j = 1; j <= n - i; j++) cout << " ";       // 前面 n-i 个空格
    for (int j = 1; j <= 2 * i - 1; j++) cout << "*";   // 2i-1 个星
    cout << "\n";
}

🎯 打印图形的方法：先在纸上写出每一行的“行号 i、空格数、星号数”，找出它们和 i 的关系式，再写代码。

2.5 九九乘法表

for (int i = 1; i <= 9; i++) {
    for (int j = 1; j <= i; j++) {
        printf("%d*%d=%-2d ", j, i, i * j);
    }
    printf("\n");
}

2.6 死循环与调试

for (int i = 1; i <= n; i--) { ... }   // i 越来越小，永远 <= n → 死循环
while (n > 0) { cout << n; }           // 忘了改 n → 死循环

程序卡住不动时，大概率是死循环。调试方法：在循环里临时输出变量值，看它怎么变化。

3. ⚠️ 易错点

  1. for (int i = 1; i <= n; i++); 括号后多了分号 → 循环体是空的。
  2. 累加变量没有初始化为 0，或者放在循环里面初始化（每轮都被清零）。
  3. for 里用逗号而不是分号分隔三部分。
  4. 循环变量在 for 里声明 int i，出了循环就不能再用 i 了。
  5. 嵌套循环内外层变量不要同名：内层重新写 int i 会遮住外层的 i，代码很容易看错；内层没有重新声明、直接用外层的 i，就会改动外层循环。统一外层用 i、内层用 j 最清楚。
  6. 累加和超过 int 范围 → 用 long long。

// 6-2
#include <iostream>
using namespace std;
int main() {
    int n;
    cin >> n;
    long long fact = 1, sum = 0;
    for (int i = 1; i <= n; i++) {
        fact *= i;       // fact 现在是 i!
        sum += fact;
    }
    cout << sum << "\n";
    return 0;
}
// 6-4
#include <iostream>
using namespace std;
int main() {
    int n;
    cin >> n;
    int h = n / 2 + 1;   // 上半部分（含中间行）的行数
    for (int i = 1; i <= n; i++) {
        int k = (i <= h) ? i : n + 1 - i;   // 第 i 行相当于上半部分的第 k 行
        for (int j = 1; j <= h - k; j++) cout << " ";
        for (int j = 1; j <= 2 * k - 1; j++) cout << "*";
        cout << "\n";
    }
    return 0;
}
