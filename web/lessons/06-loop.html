循环：一圈一圈重复做事

先看动画，再做小测，最后一定要在 Dev-C++ 里自己敲一遍。黄色高亮是「这一步刚变的地方」。看不懂就点「🙋 我不懂这里」，页面底部会生成一行文字，发给老师就行。

1. for 循环：初始化 → 判断 → 循环体 → 更新

for (int i = 1; i <= 3; i++) 的执行顺序：先初始化一次，然后反复“判断 → 循环体 → 更新”，直到判断不成立。注意最后一次判断失败时，循环体不会执行。

2. break 和 continue

continue：跳过这一圈剩下的代码，去做更新、进入下一圈。break：整个循环马上结束。

3. 拆数位：while + % 10 + / 10

n % 10 取出个位，n / 10 去掉个位。重复到 n 变成 0，就把每一位都处理了。

4. 判断质数：只试到 √n

如果 n = a × b 且 a ≤ b，那么 a ≤ √n，所以只需要试到 √n。写成 i <= n / i，既避免浮点误差，也避免 i * i 溢出。点上面的按钮可以换一个 n 再看一遍。

5. 嵌套循环：打印图形

外层管“第几行”，内层管“这一行打印什么”。先在纸上写出每一行的行号和星号数，找到它们的关系，再写代码。
