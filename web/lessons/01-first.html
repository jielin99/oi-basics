第 1 课 第一个程序：C++ 程序长什么样

预计用时：1 周 本课目标：看懂 C++ 程序的骨架；会用 cout 输出文字和计算结果；理解分号、花括号、注释。

1. 从 Python 说起

同一个功能，两种语言对比：

# Python
print("Hello")
print(3 + 4)
// C++
#include <iostream>
using namespace std;

int main() {
    cout << "Hello" << endl;
    cout << 3 + 4 << endl;
    return 0;
}

C++ 多出来的那些东西，每一行都有用：

代码作用Python 里对应的
#include <iostream>引入输入输出库（cin、cout 在里面）import（但 Python 的 print 不用 import）
using namespace std;让我们能直接写 cout，否则要写 std::cout类似 from xxx import *
int main() { ... }主函数，程序从这里开始执行，必须有且只有一个Python 从文件第一行开始执行
;每条语句结尾的分号Python 靠换行区分语句
{ }花括号包住一段代码Python 靠缩进
return 0;告诉系统“程序正常结束”无

💡 重要观念转变：Python 里缩进是语法，缩进错了就报错；C++ 里花括号才是语法，缩进只是给人看的。但缩进仍然要写整齐——这是好习惯，不是可选项。

2. 知识点

2.1 用 cout 输出

#include <iostream>
using namespace std;

int main() {
    cout << "I love OI";          // 输出文字，文字要用双引号
    cout << endl;                 // endl 表示换行
    cout << "Line 2\n";           // \n 也是换行，写在字符串里面
    cout << 10 << " " << 20 << endl;  // 可以用 << 连续接多个东西
    cout << 7 * 6 << endl;        // 输出计算结果：42
    cout << "7 * 6" << endl;      // 加了引号就是文字：7 * 6
    return 0;
}

运行结果：

I love OI
Line 2
10 20
42
7 * 6

和 Python print 的区别：

  • cout 不会自动换行，也不会自动在两个值之间加空格。要什么就得自己写什么。
  • << 可以理解为“把右边的东西送进输出流”，箭头方向指向 cout。
🎮 动手看看

2.2 endl 和 "\n"

两者都换行。区别是 endl 还会“刷新缓冲区”，速度慢一点。数据量大时用 "\n"，平时随意。建议直接养成用 "\n" 的习惯。

3. ⚠️ 易错点

  1. 漏分号：编译器报错的行号常常是下一行，因为它读到下一行才发现上一行没结束。
  2. 中文标点：； （ ） “ ” 全部是错的，必须英文半角。
  3. 大小写：C++ 区分大小写，Cout、Main、Return 全是错的。
  4. 花括号不配对：每写一个 { 立刻写好 }，再往中间填内容。
  5. main 写错：本课程统一写 int main()，不能写 void main()（g++ 直接报错）。
🎮 动手看看
