第 3 课 输入输出：比赛里的 I/O 全套功夫

预计用时：1 周 本课目标：熟练编写一套输入输出（cin/cout 或 scanf/printf），能读懂另一套；会保留指定位数小数；能认出并套用“读入不知道有多少个数据”的写法（第 6 课再要求独立写）；知道加速两行怎么用、加了之后有什么限制。

1. 从 Python 说起

# Python
a, b = map(int, input().split())   # 读一行里的两个整数
print(f"{3.14159:.2f}")            # 保留两位小数：3.14
// C++
int a, b;
cin >> a >> b;                     // 不管两个数是在一行还是两行，都能读
printf("%.2f\n", 3.14159);         // 3.14

好消息：C++ 的 cin 比 Python 的 input() 省心——它自动跳过空格和换行，你不用关心数据是怎么分行的。

2. 知识点

2.1 cin 读入

int n;
double x;
char c;
cin >> n >> x >> c;   // 输入 "5 3.2 Q" 或者分三行输入都可以

cin 按变量类型来读：读 int 就读一个整数，读 char 就读一个非空白字符。

2.2 scanf / printf（C 风格，比赛常用）

scanf 和 printf 来自头文件 <cstdio>，需要用格式符告诉它类型：

类型格式符读入例子输出例子
int%dscanf("%d", &n);printf("%d", n);
long long%lldscanf("%lld", &x);printf("%lld", x);
double读 %lf，写 %fscanf("%lf", &d);printf("%f", d);
char%cscanf(" %c", &c);（%c 前加空格跳过空白）printf("%c", c);
字符串（char 数组）%sscanf("%s", s);（不加 &）printf("%s", s);

⚠️ scanf 读入普通的 int、long long、double、char 变量时，要在变量前加 &（传地址，第 12 课解释原因），例如 &n。读入字符数组的 %s 写法不同，按上表示例不加 &。参数写错时程序行为没有保证：可能崩溃，也可能读出错误的值。

2.3 控制输出格式（重点）

#include <cstdio>
int main() {
    double pi = 3.1415926;
    printf("%.2f\n", pi);      // 3.14       保留 2 位小数（四舍五入）
    printf("%.0f\n", 2.5);     // 2 或 3     和运行库有关，不一定是你以为的四舍五入，见易错点
    printf("%5d|\n", 42);      //    42|     宽度 5，右对齐
    printf("%-5d|\n", 42);     // 42   |     宽度 5，左对齐
    printf("%05d\n", 42);      // 00042      宽度 5，前面补 0
    printf("%d+%d=%d\n", 1, 2, 3);   // 1+2=3   可以混在文字里
    printf("100%%\n");         // 100%       输出百分号要写两个 %%
    return 0;
}

cout 也能保留小数，但写法啰嗦：

#include <iomanip>
cout << fixed << setprecision(2) << pi << "\n";   // 3.14

建议：初学时一个程序里只选一种风格。 要保留小数、补 0，可以整个程序都用 scanf/printf；也可以全用 cin/cout，小数用上面的 fixed << setprecision(k)。两种都要能看懂——初赛题和很多题解用的是 scanf/printf。

如果用了 2.5 节的加速两行（模板里有），就只能全用 cin/cout。

2.4 读入不定数量的数据

题目说“输入若干个整数，直到文件结束”：

int x, sum = 0;
while (cin >> x) {        // 读成功返回 true，读到末尾返回 false
    sum += x;
}
cout << sum << "\n";

scanf 版本：while (scanf("%d", &x) == 1) { ... }——返回值是“成功读到了几个数”，等于 1 才继续。（有的资料写 != EOF，它只判断“文件结束”，遇到读不成数字的内容时会一直循环下去。）

在本地测试时，输完数据后按 Ctrl+Z 再回车（Windows）表示“输入结束”。

题目说“先输入 n，再输入 n 个数”（最常见）：

int n;
cin >> n;
for (int i = 1; i <= n; i++) {   // 循环第 6 课细讲，这里先照抄
    int x;
    cin >> x;
    // 处理 x
}

2.5 加速：数据量大时必用

cin/cout 默认比较慢。读入超过 10⁵ 个数时，在 main 开头加两行：

ios::sync_with_stdio(false);
cin.tie(nullptr);

⚠️ 加了这两行以后，不能再混用 cin 和 scanf（或 cout 和 printf），否则输出顺序会乱。要么全用 C++ 风格，要么全用 C 风格。

2.6 一个完整例子

输入一个学生的语文、数学、英语成绩（整数），输出总分和平均分（保留 2 位小数）。

#include <cstdio>

int main() {
    int a, b, c;
    scanf("%d %d %d", &a, &b, &c);
    int total = a + b + c;
    double avg = total / 3.0;        // 3.0 不是 3！
    printf("%d %.2f\n", total, avg);
    return 0;
}

3. ⚠️ 易错点

  1. scanf 读普通变量忘记 & → 行为没有保证，常见是崩溃（RE），也可能读出错误的值。
  2. double 用 scanf("%f") 读 → 读出错误值，必须用 %lf。
  3. long long 用 %d → 结果错乱，必须用 %lld。
  4. 输出多了提示文字（cout << "请输入n:"）→ WA。比赛程序只输出题目要求的内容。
  5. 保留小数位和课本上的十进制四舍五入不完全相同：恰好在“5”的边界附近时，结果会受到浮点数表示和运行库的影响（比如 printf("%.0f", 2.5) 在有的环境输出 2，有的输出 3）。本阶段按题目要求用格式输出即可，不要背“2.5 一定输出几”。(int)(x + 0.5) 只是对正数、一般范围内够用的近似技巧，不是严格的通用方法。
  6. 加速后混用 cin 与 scanf → 顺序乱。

4. 课堂练习

练习 3-1：输入一个圆的半径 r（小数），输出周长和面积，保留 3 位小数，π 取 3.14159。

练习 3-2：输入 hh mm（如 9 5），以 09:05 的格式输出。

练习 3-3（体验题）：输入若干个整数（个数未知），输出它们的个数和总和。要用到 2.4 节的 while 写法，照着套用即可，第 6 课会细讲循环；这题不要求现在就能默写。

点击查看参考答案
// 3-2
#include <cstdio>
int main() {
    int h, m;
    scanf("%d %d", &h, &m);
    printf("%02d:%02d\n", h, m);
    return 0;
}
// 3-3
#include <iostream>
using namespace std;
int main() {
    int x, cnt = 0;
    long long sum = 0;
    while (cin >> x) {
        cnt++;
        sum += x;
    }
    cout << cnt << " " << sum << "\n";
    return 0;
}
