第 9 课 函数与递归

预计用时：1.5 周 本课目标：会定义和调用函数；理解值传递与引用传递；理解全局变量与局部变量；会写简单递归，并理解递归的执行过程。

分次学习：第一次学 2.1~2.5（函数、参数、作用域）；第二次学 2.6 递归的阶乘和朴素斐波那契。记忆化和汉诺塔暂作了解，能看懂即可，算法阶段还会再学。

1. 从 Python 说起

# Python
def add(a, b):
    return a + b

def show(msg):
    print(msg)          # 没有返回值
// C++
int add(int a, int b) {        // 返回值类型  函数名(参数类型 参数名, ...)
    return a + b;
}

void show(string msg) {        // void 表示没有返回值
    cout << msg << "\n";
}

区别：

  1. 要写返回值类型和每个参数的类型。
  2. 没有返回值用 void。
  3. 函数要写在调用它的地方之前（或者先写一个声明）。
  4. 不能像 Python 那样一次返回多个值（return a, b）。需要返回多个结果时用引用参数（见 2.3）或结构体（第 10 课）。

2. 知识点

2.1 函数的定义和调用

#include <iostream>
using namespace std;

bool isPrime(int n) {
    if (n < 2) return false;
    for (int i = 2; i <= n / i; i++)    // 即 i*i <= n，这样写不会溢出（见第 6 课）
        if (n % i == 0) return false;   // return 会立即结束函数
    return true;
}

int main() {
    for (int i = 1; i <= 50; i++)
        if (isPrime(i)) cout << i << " ";
    cout << "\n";
    return 0;
}

🎯 什么时候该写函数？ 同样的代码要用两次以上，或者某一段逻辑独立、可以起个名字（比如 isPrime、isLeap、digitSum）。函数让主程序更清晰，也更容易单独测试。

2.2 值传递：函数拿到的是“复印件”

void change(int x) {
    x = 100;            // 改的是复印件
}

int main() {
    int a = 5;
    change(a);
    cout << a << "\n";  // 还是 5
}

2.3 引用传递：函数拿到的是“原件”

在参数类型后加 &：

void change(int &x) {   // x 是 a 的“别名”
    x = 100;
}

int main() {
    int a = 5;
    change(a);
    cout << a << "\n";  // 100
}

引用的典型用途

// ① 交换两个数（标准库其实已经有 swap，这里理解原理）
void mySwap(int &a, int &b) {
    int t = a; a = b; b = t;
}

// ② 一次“返回”多个结果
void divide(int a, int b, int &q, int &r) {
    q = a / b;
    r = a % b;
}
// 调用：int q, r; divide(17, 5, q, r);  → q=3, r=2

💡 和 Python 对比：Python 里传列表进函数，在函数里修改会影响外面；传整数则不会。C++ 里默认都是复印件（包括 string、vector），想改原件必须写 &。

2.4 数组作为参数

数组传进函数时不是复印件，函数里改了会影响外面（原因见第 12 课指针）：

void fill(int a[], int n) {
    for (int i = 1; i <= n; i++) a[i] = i * i;
}

不过信奥里更常见的做法是：数组开成全局的，函数直接用，不需要传参。

2.5 全局变量与局部变量

int n;              // 全局变量：所有函数都能用，自动初始化为 0
int a[100010];

void work() {
    int cnt = 0;    // 局部变量：只在 work 里有效，每次调用重新创建
    for (int i = 1; i <= n; i++) ...
}
  • 局部变量和全局变量同名时，局部的优先（会“挡住”全局的）——这经常导致 bug。比如全局有 n，main 里又写了 int n; cin >> n;，那么其他函数看到的全局 n 还是 0。
  • 🎯 信奥常用风格：n、数组等题目数据放全局；循环变量、临时变量放局部。不要在 main 里重复声明全局已有的变量。

2.6 递归：函数调用自己

例 1：阶乘 n! = n × (n−1)!，0! = 1（适用于 0 ≤ n ≤ 20：21! 已经超过 long long）

long long fact(int n) {
    if (n == 0) return 1;           // ① 终止条件（出口）
    return n * fact(n - 1);         // ② 递归调用，规模变小
}

执行 fact(3) 的过程：

fact(3) = 3 * fact(2)
              fact(2) = 2 * fact(1)
                            fact(1) = 1 * fact(0)
                                          fact(0) = 1      ← 到底了，开始返回
                            fact(1) = 1 * 1 = 1
              fact(2) = 2 * 1 = 2
fact(3) = 3 * 2 = 6

写递归的两要素：

  1. 出口：什么时候不再递归，直接返回结果。
  2. 递推关系：怎样把大问题变成规模更小的同类问题。

缺了出口 → 无限递归 → 程序崩溃（栈溢出，RE）。

例 2：斐波那契数列 f(1)=f(2)=1，f(n)=f(n−1)+f(n−2)

int fib(int n) {
    if (n <= 2) return 1;
    return fib(n - 1) + fib(n - 2);
}

⚠️ 这个写法非常慢：fib(40) 要调用两亿多次。因为 fib(38) 被算了 2 次、fib(37) 被算了 3 次……同一个值被反复计算。改进办法：用数组记住算过的结果（“记忆化”），这是以后学动态规划的起点。

long long memo[100];                         // 适用于 1 ≤ n ≤ 90：f(93) 起超过 long long
long long fib2(int n) {
    if (n <= 2) return 1;
    if (memo[n] != 0) return memo[n];        // 算过了，直接返回
    return memo[n] = fib2(n - 1) + fib2(n - 2);
}

例 3：汉诺塔（递归思想的经典）

// 把 n 个盘子从 from 柱借助 mid 柱移到 to 柱
void hanoi(int n, char from, char mid, char to) {
    if (n == 0) return;
    hanoi(n - 1, from, to, mid);                      // 上面 n-1 个先挪到中间
    cout << from << "->" << to << "\n";               // 最大的盘子挪到目标
    hanoi(n - 1, mid, from, to);                      // 中间 n-1 个挪到目标
}

🎯 理解递归分两步：

  1. 先展开小例子：刚学时拿很小的 n（如 fact(3)、hanoi(2, 'A', 'B', 'C')）像上面那样一层层写出来，看清“谁在暂停等待、每一层的 n 是多少、结果按什么顺序返回”。
  2. 再学会“相信”：熟悉执行过程以后，n 一大就不可能逐层展开了。这时相信“函数能正确解决规模更小的问题”，只考虑当前这一层怎么利用它。

3. ⚠️ 易错点

  1. 有返回值的函数，某些路径忘写 return → 这是程序错误，结果不可靠，甚至可能崩溃（不是“返回一个随机数”那么简单）。加 -Wall 编译器会警告。
  2. 想在函数里修改外面的变量，忘了写 &。
  3. 局部变量和全局变量同名，main 里重复声明 int n。
  4. 递归没有出口或出口写错 → RE。
  5. 递归太深（比如递归 10⁶ 层）→ 栈溢出。

练习 9-5：上楼梯，每次可以走 1 级或 2 级，走到第 n 级有多少种走法？（n ≤ 40，想想和斐波那契的关系）

点击查看参考答案
// 9-3
int gcd(int a, int b) {
    if (b == 0) return a;
    return gcd(b, a % b);
}
// 9-4
void printDigits(int n) {
    if (n >= 10) printDigits(n / 10);   // 先输出前面的高位
    cout << n % 10 << " ";              // 再输出个位
}

9-5：走到第 n 级，最后一步要么从 n−1 级走 1 步，要么从 n−2 级走 2 步，所以 f(n) = f(n−1) + f(n−2)，f(1)=1，f(2)=2。用记忆化或循环做。
