第 2 课 变量与数据类型：C++ 和 Python 最大的不同

预计用时：1 周（这一课最重要，宁可多花时间） 本课目标：掌握 int、long long、double、char、bool；理解溢出；掌握 C++ 整数除法和取模；会做类型转换。

1. 从 Python 说起

# Python：变量不用声明类型，什么都能装，整数无限大
x = 10
x = "hello"     # 没问题
big = 2 ** 100  # 没问题，Python 整数没有上限
print(7 / 2)    # 3.5
print(7 // 2)   # 3
print(-7 // 2)  # -4
print(-7 % 2)   # 1
// C++：变量必须先声明类型，类型定了就不能变
int x = 10;
x = "hello";        // ❌ 编译错误！int 只能装整数
int big = 1 << 40;  // ❌ 错误！int 只有 32 位，移 40 位本身就不合法，结果不可靠
cout << 7 / 2;      // 3   ← 两个整数相除，结果还是整数！
cout << -7 / 2;     // -3  ← 和 Python 不一样！
cout << -7 % 2;     // -1  ← 和 Python 不一样！

从 Python 换到 C++，这一课有三条规则要切换过来：

  1. Python：变量可以随时装别的类型 → C++：变量有固定类型
  2. Python：整数没有上限 → C++：整数有范围，超了就溢出，程序运行时不会提醒你，结果也不能再信
  3. Python：/ 是普通除法 → C++：整数 / 整数 = 整数

2. 知识点

2.1 声明变量

int a;            // 声明一个整数变量 a（局部变量此时的值不确定，不能读！）
int b = 5;        // 声明并赋初值（推荐）
int c = 1, d = 2; // 一次声明多个
a = b + c;        // 之后可以随意赋值，但必须是同类型（或能自动转换的）

⚠️ 在 main 里面声明的变量如果不赋初值，它的值是不确定的，读它得到的结果不能依赖（这次看着正常，换台电脑、换个编译选项就可能变）。Python 里不赋值根本没法用，C++ 能编译通过，但结果不可靠。养成声明时就赋初值的习惯，尤其是 sum = 0、cnt = 0。

2.3 溢出：最隐蔽的错误

#include <iostream>
using namespace std;

int main() {
    int a = 2147483647;   // int 的最大值
    a = a + 1;
    cout << a << "\n";    // ❌ 溢出！常见环境下会看到 -2147483648，但这不是规则，不能依赖

    int x = 100000, y = 100000;
    cout << x * y << "\n";            // ❌ 溢出！可能看到 1410065408 之类的怪数，不能依赖
    long long z = x * y;
    cout << z << "\n";                // 仍然错误！因为 x*y 先按 int 算完溢出了，再装进 long long
    long long w = (long long)x * y;
    cout << w << "\n";                // 正确：10000000000
    return 0;
}

💡 溢出发生在“计算的那一刻”，而不是“存储的那一刻”。 两个 int 相乘，结果就是 int，已经溢出了，再赋给 long long 也救不回来。必须先把其中一个转成 long long 再乘。

最简单的办法：只要可能超过 21 亿，所有相关变量一开始就声明成 long long。

⚠️ 上面两行错误输出只是“某次运行看到的样子”，不要把这些数当成规律去背。C++ 规定：有符号整数溢出以后，程序的结果就没有保证了（换编译器、加 -O2 都可能变）。要记住的只有一条：在运算之前就用够大的类型。

2.4 算术运算：整除与取模

运算C++ 写法例子结果
加减乘+ - *7 * 214

小数除法/（至少一边是小数）7.0 / 23.5

负数的整除和取模——和 Python 不一样（初赛常考）：

表达式PythonC++C++ 的规则

整除和取模的经典用法——拆数位：

int n = 1234;
int ge  = n % 10;         // 个位：4
int shi = n / 10 % 10;    // 十位：3
int bai = n / 100 % 10;   // 百位：2
int qian = n / 1000;      // 千位：1

2.5 类型转换

int a = 7, b = 2;
double r1 = a / b;            // 3.0   ← 先算 a/b=3（整数除法），再转成 3.0
double r2 = (double)a / b;    // 3.5   ← 先把 a 转成 7.0，再除
double r3 = a * 1.0 / b;      // 3.5   ← 常用技巧：乘 1.0
int c = 3.99;                 // 3     ← 小数转整数，直接砍掉小数部分（不是四舍五入！）
int d = (int)(3.99 + 0.5);    // 4     ← 正数四舍五入的近似技巧（一般够用，不是严格方法，见第 3 课）

规则：运算时，“小”类型自动向“大”类型看齐（int 和 double 运算 → double；int 和 long long 运算 → long long）。

3. ⚠️ 易错点

  1. 求平均数写成 sum / n，sum 和 n 都是 int → 结果被截断。应写 sum * 1.0 / n。
  2. 两个大 int 相乘赋给 long long → 已经溢出。
  3. 局部变量没赋初值就用来累加 → 结果不可靠。
  4. char 用双引号 "A" → 那是字符串，不是字符。
  5. 想算 2¹⁰ 写成 2^10 → ^ 在 C++ 里是异或，结果是 8。

4. 课堂练习

练习 2-1：预测下面每行的输出，然后上机验证。错了的要搞懂为什么。

cout << 17 / 5 << "\n";
cout << 17 % 5 << "\n";
cout << 17.0 / 5 << "\n";
cout << -17 / 5 << "\n";
cout << -17 % 5 << "\n";
cout << (int)2.9 << "\n";
cout << 2 ^ 3 << "\n";     // 拓展·找错：这一行会编译报错，想想为什么（不用预测输出）

练习 2-2：一个三位数 n = 358，用程序输出它反过来的数 853。

练习 2-3：小明有 1000000 元，每年翻 3 倍，3 年后有多少钱？用 int 和 long long 各写一次，比较结果。

练习 2-4：输入秒数 t = 3725，输出它是几小时几分几秒（1 2 5）。

点击查看参考答案

2-1：3、2、3.4、-3、-2、2。最后一行：<< 优先级比 ^ 高，相当于 (cout << 2) ^ (3 << "\n")，编译报错。应写 cout << (2 ^ 3)，结果是 1（异或，第 12 课讲）。

2-2：

int n = 358;
int r = n % 10 * 100 + n / 10 % 10 * 10 + n / 100;
cout << r << "\n";

2-3：1000000 * 27 = 27000000，int 也装得下。但若改成翻 3 倍 10 年（×59049）就会溢出——试试看。

2-4：

int t = 3725;
cout << t / 3600 << " " << t % 3600 / 60 << " " << t % 60 << "\n";
✍️ 回到 Dev-C++ 自己试一试
  1. 把类型转换的例子敲一遍，把 a、b 改成 9 和 4，先猜四个结果，再运行。
  2. 在 Dev-C++ 里亲自试一下 cout << 2147483647 + 1;，看看你的电脑上显示什么——然后记住：这不是规律，不要依赖它。
