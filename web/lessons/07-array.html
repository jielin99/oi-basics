第 7 课 数组：C++ 版的“列表”，但很不一样

预计用时：1.5 周 本课目标：会定义、读入、遍历一维和二维数组；理解数组越界的危害；知道大数组为什么开在全局；掌握“桶计数”等数组基本用法。

2. 知识点

2.1 定义与访问

int a[5];                    // 5 个 int：a[0] a[1] a[2] a[3] a[4]，没有 a[5]！
int b[5] = {1, 2, 3};        // b = {1, 2, 3, 0, 0}，没写的自动补 0
int c[5] = {0};              // 全部是 0
double d[100];
a[0] = 10;
a[4] = a[0] * 2;
  • 下标从 0 到 大小−1。
  • 数组大小必须是常量（const int N = 1000; int a[N];）。

2.2 下标从 1 开始的习惯

信奥题目里数据常常是“第 1 个 … 第 n 个”。为了不在 0 和 1 之间来回换算，我们习惯从下标 1 开始存，并且数组多开一些：

const int N = 100000 + 10;   // 题目说 n ≤ 100000
int a[N];

int main() {
    int n;
    cin >> n;
    for (int i = 1; i <= n; i++) cin >> a[i];   // a[1] ~ a[n]
}

2.3 大数组开在全局

int big[1000000];            // ✅ 开在 main 外面（全局）：自动全部为 0，空间大

int main() {
    int small[1000000];      // ❌ 开在 main 里（局部）：值不确定，而且太大会“爆栈”导致程序崩溃
}

🎯 规则：数组一律开在 main 外面。 这一条能帮你避免大量莫名其妙的错误。

2.4 数组越界：最危险的 bug

int a[10];
a[10] = 5;     // 越界！编译器不会拦你，但可能改坏了别的变量
a[100000] = 1; // 越界很多，常见结果是程序崩溃（RE），但也不保证一定崩溃

越界的常见原因：

  • 数组开小了（没仔细看数据范围）
  • 循环条件写成了 i <= n 但数组只开了 n
  • 计算 a[i-1] 时 i=0，或 a[i+1] 时 i=n

🎯 防御方法：按数据范围开数组时多开 5~10 个。但这只是保险，不能代替把下标算对——循环多跑一次，读到多开的那几个格子，程序不会崩溃，答案却悄悄错了。写完循环要检查：第一个和最后一个访问的下标分别是多少？

2.5 常见操作

遍历求和、求最值

long long sum = 0;
int mx = a[1];
for (int i = 1; i <= n; i++) {
    sum += a[i];
    if (a[i] > mx) mx = a[i];
}

逆序输出

for (int i = n; i >= 1; i--) cout << a[i] << " ";

清空数组：memset（需要 <cstring>）

memset(a, 0, sizeof(a));    // 全部设为 0
memset(a, -1, sizeof(a));   // 全部设为 -1
memset(a, 1, sizeof(a));    // ⚠️ 不是全 1！是 16843009

memset 是按字节填充的：每个 int 有 4 个字节，每个字节都填成 1，拼起来就是 16843009。所以对 int 数组，它只适合清 0 和设成 -1：每个字节全是 0，拼起来是 0；每个字节全是二进制 1，拼起来恰好是 -1。想把数组全部设成别的值，用循环或 fill（在 <algorithm> 里）：

fill(a, a + 100, 1);         // a[0]~a[99] 全部设为 1

桶（计数数组）——非常重要的思想

输入 n 个 1~100 之间的整数，统计每个数出现了几次。

int cnt[110];     // cnt[x] 表示 x 出现的次数，全局自动为 0
int main() {
    int n;
    cin >> n;
    for (int i = 1; i <= n; i++) {
        int x; cin >> x;
        cnt[x]++;           // 把 x 放进第 x 号“桶”
    }
    for (int x = 1; x <= 100; x++) {
        if (cnt[x] > 0) cout << x << ": " << cnt[x] << "\n";
    }
}

用数值本身当下标——这个技巧在“去重”“判断是否出现过”“计数排序”中反复出现。

2.6 二维数组

int g[110][110];   // 110 行 110 列

int main() {
    int n, m;
    cin >> n >> m;
    for (int i = 1; i <= n; i++)
        for (int j = 1; j <= m; j++)
            cin >> g[i][j];

    // 按行输出
    for (int i = 1; i <= n; i++) {
        for (int j = 1; j <= m; j++) cout << g[i][j] << " ";
        cout << "\n";
    }
}

g[i][j] 表示第 i 行第 j 列。二维数组常用于：矩阵、地图、棋盘、表格。

方向数组（以后搜索题必备，先认识一下）：

int dx[4] = {-1, 1, 0, 0};    // 上 下 左 右
int dy[4] = {0, 0, -1, 1};
for (int k = 0; k < 4; k++) {
    int nx = x + dx[k], ny = y + dy[k];   // (x,y) 的四个邻居
}

3. ⚠️ 易错点

  1. 数组开小了 / 下标越界 → WA 或 RE，而且难以发现。
  2. 局部数组没初始化 → 值不确定，结果不可靠。
  3. memset(a, 1, sizeof(a)) 以为能全设成 1。
  4. 二维数组太大：int g[10000][10000] 需要约 400MB → 超内存。估算方法：元素个数 × 4 字节。
  5. 想用 a = b 复制数组 → 不能这样写，要用循环逐个复制。

// 7-3
#include <iostream>
using namespace std;
bool seen[1010];
int main() {
    int n;
    cin >> n;
    for (int i = 1; i <= n; i++) {
        int x; cin >> x;
        seen[x] = true;
    }
    for (int x = 0; x <= 1000; x++)
        if (seen[x]) cout << x << " ";
    cout << "\n";
    return 0;
}
// 7-5
#include <iostream>
using namespace std;
int c[25][25];
int main() {
    int n;
    cin >> n;
    for (int i = 1; i <= n; i++) {
        c[i][1] = c[i][i] = 1;
        for (int j = 2; j < i; j++) c[i][j] = c[i-1][j-1] + c[i-1][j];

        cout << "\n";
    }

}
