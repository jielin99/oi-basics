数组：一排带编号的格子

先看动画，再做小测，最后一定要在 Dev-C++ 里自己敲一遍。黄色高亮是「这一步刚变的地方」。看不懂就点「🙋 我不懂这里」，页面底部会生成一行文字，发给老师就行。

1. 下标从 0 开始

数组 a[5] 有 5 个格子，编号（下标）是 0、1、2、3、4，没有 a[5]。没写的格子自动补 0。

2. 越界：最危险的 bug

数组只有 3 个格子，循环却多跑了一圈。注意：C++ 不会提醒你，下面红色的格子是课件替你画出来的。

3. 桶计数：用数值本身当下标

要数「每个数字出现了几次」，就准备一排桶，数字 x 来了就往第 x 号桶里加 1。

4. 二维数组：行和列

g[i][j] 是第 i 行第 j 列。双重循环里，外层管行，内层管列。
